Diagnóstico aéreo: NDVI, NDRE y VARI

Herramienta para explorar imágenes de mandarina, caña de azúcar y zarzamora. Calcula índices píxel a píxel cuando la imagen contiene las bandas espectrales necesarias.

1 · Configurar análisis

El procesamiento se hace en este navegador. Para NDVI y NDRE necesitas un GeoTIFF multibanda con datos espectrales, no una captura o foto RGB común.

Orden inicial supuesto: 1=Rojo, 2=Verde, 3=Azul, 4=NIR, 5=Red Edge. Confirma el orden real en los metadatos del sensor. Si el GeoTIFF tiene menos de 5 bandas, cambia los números o NDRE no estará disponible.

Fórmulas:
NDVI = (NIR − Rojo) / (NIR + Rojo)
NDRE = (NIR − Red Edge) / (NIR + Red Edge)
VARI = (Verde − Rojo) / (Verde + Rojo − Azul)
NDVI y NDRE requieren las bandas correspondientes. Un JPG/PNG RGB solo permite calcular VARI.
